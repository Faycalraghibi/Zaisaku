# Advanced Institutional Forensic AI Features & Portfolio Showcase Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform Zaisaku into an institutional-grade, feature-rich financial intelligence platform suitable for high-end enterprise client acquisition by adding multi-year financial & accrual trend charts with AI anomaly markers, in-app interactive SEC filing annotation viewer, autonomous multi-agent forensic investigation runner, sector peer comparative matrix, and an interactive architecture showcase.

**Architecture:** 
- Backend adds three specialized forensic services: `TrendsAnalyzer` for multi-year financial/accrual anomaly detection, `PeerAnalyzer` for comparative sector benchmarking, and `InvestigationOrchestrator` for streaming autonomous multi-agent audit executions via Server-Sent Events (SSE).
- Frontend adds interactive SVG time-series charts, an in-app split-pane SEC document annotation studio with text-selection AI queries, an animated multi-agent investigation execution modal, a sector risk matrix, and a portfolio engineering architecture drawer.

**Tech Stack:** Python 3.11, FastAPI, Pydantic v2, Pytest, Vue 3.5, Vite 8, Tailwind CSS v4, Lucide Vue Next, Server-Sent Events (SSE).

**Spec:** User request: "Can you add more features to this app? It is looking like it is generated by AI and I want more features because I want to use it in my profile. For freelancing. The goal of this is to attract clients of any domain, especially the financial domain. I want them to see that I can add AI functionalities to their sites and that is the goal."

## Global Constraints

- Preserve all 136 existing backend tests with zero regressions.
- All code in `backend/` must pass `ruff check backend/` cleanly.
- Frontend must build cleanly with `npm --prefix frontend run build` with zero errors.
- Preserve the Apple design philosophy (tactile pointer feedback, translucent materials, spring transitions, system typography).
- Keep the landing screen as the Company Forensic Intelligence Hub (chat remains an on-demand slide-over drawer).

## Review Focus

1. **Division by Zero in Financial Trends:** Handling zero or missing previous period values in financial ratio and growth calculations safely.
2. **SSE Streaming Lifecycle:** Ensuring `InvestigationOrchestrator` yields properly formatted SSE payloads (`event:` and `data:`) with error recovery on client abort.
3. **SVG Responsive Scaling:** SVG charts must scale fluidly across desktop and mobile screens with dynamic viewBox calculation and proper padding.
4. **Peer Benchmarking Consistency:** Sector peer matrix must handle tickers with varying numbers of available historical filings without crashing.
5. **Interactive Text Selection in Filing Viewer:** Handling selection offsets cleanly so users can highlight any sentence in the SEC filing without DOM range errors.
